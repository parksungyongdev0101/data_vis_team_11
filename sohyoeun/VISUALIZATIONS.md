# AI 시대 개발자 — 시각화 예시 모음

질문 2 _"AI 시대에 개발자는 무엇을·어떤 역량을 준비해야 하는가"_ 를 탐색하기 위한 인터랙티브 시각화 프로토타입 4종.

- 라이브러리: **D3.js v7** (CDN 로드 → 실행 시 인터넷 연결 필요)
- 다크 테마 SVG 기반, 한국어 UI

### 데이터셋 (정확 표기)

| 약칭               | 정식 명칭 / 연도                                | 사용 파일                               | 응답 수   |
| ------------------ | ----------------------------------------------- | --------------------------------------- | --------- |
| **SO 2025**        | Stack Overflow Annual Developer Survey **2025** | `survey_results_public.csv`             | 49,191    |
| **JetBrains 2025** | JetBrains Developer Ecosystem Survey **2025**   | `developer_ecosystem_2025_external.csv` | 약 24,500 |

## 1. `ai_task_scatter.html` — AI × 작업/분야 축 선택 산점도

**목적**: AI가 어떤 작업을 가져가고 사람은 무엇을 쥐는지를, 축을 바꿔가며 탐색.

**데이터**: 더미 — **SO 2025 · JetBrains 2025** 필드를 모사

**점 단위 토글**: 작업(task) ↔ 분야(role)

**축으로 쓰는 지표 (점마다 측정 가능한 값만)**

| 점 단위 | 축 후보                                | 대응 실제 필드                                    |
| ------- | -------------------------------------- | ------------------------------------------------- |
| 작업    | AI 사용 빈도                           | JetBrains `ai_coding_tasks_freq` (작업별 빈도)    |
| 작업    | 위임 의향(≈신뢰)                       | JetBrains `ai_coding_delegate` (작업별 위임 의향) |
| 작업    | 현재 AI 사용률 / 향후 확대 / 사람 유지 | SO `AITool` (워크플로 단계별 현재·예정·미사용)    |
| 분야    | AI 사용률·매일 사용·위협 인식          | SO `AISelect`, `AIThreat` (DevType별 집계)        |
| 분야    | 직무 만족도 / 연봉                     | SO `JobSat`, `ConvertedCompYearly` (DevType별)    |

**우측 신뢰 게이지** (작업별로 안 쪼개지는 전반 지표): SO `AIAcc`(정확도 신뢰), `AIComplex`(복잡작업 처리력)

**가공 방식 (실데이터 적용 시)**

- 작업 축: 매트릭스 문항을 작업별 "사용 비율 / 위임 의향 %"로 환산
- 분야 축: 개인 응답을 `DevType`로 그룹화 → 평균·비율
- 신뢰 게이지: 전체 응답의 범주 분포(%)

**인터랙션**: X/Y 축 드롭다운, 작업/분야 토글, 연차(전체·주니어·시니어) 토글, 사분면 자동 라벨, 점 클릭→상세, 범례 카테고리 on/off

## 2. `ai_task_dashboard.html` — 멀티뷰 대시보드

**목적**: 위 작업 분석을 **세 뷰 + 게이지**로 한 화면에 연동.

**구성 뷰**

- ① 탐색 산점도 (1번과 동일, 점=작업)
- ② 라이프사이클 침투 링 — 작업을 8단계(기획→설계→코딩→테스트→리뷰→문서→배포·운영→탐색·학습)로 묶어, 바깥으로 길수록 AI 깊이 침투
- ③ 사용 vs 신뢰 덤벨 — ●사용(`freq`) ↔ ○신뢰(`delegate`), 선 길이=간극
- AI 신뢰도 게이지 — SO `AIAcc`/`AIComplex`

**데이터**: 더미 — 1번과 동일 (**SO 2025** `AITool`·`AIAcc`·`AIComplex`, **JetBrains 2025** `ai_coding_tasks_freq`/`ai_coding_delegate` 모사).
작업마다 **라이프사이클 단계(stage)** 를 부여(파생 분류)해 링이 단계별로 집계.

**가공 방식 (실데이터 적용 시)**

- 작업 12개에 stage 라벨 매핑 → 링은 stage별 가중평균(응답자 수 가중)
- 덤벨 정렬 = 사용−신뢰 간극 내림차순

**인터랙션 (연동)**: 한 작업을 **어느 뷰에서든 hover → 세 뷰 동시 강조** (링은 해당 stage 강조), 연차 토글 **전체 공유**, 산점도 축 드롭다운, 범례 stage hover

## 3. `aiopen_network.html` — "AI 시대에 남을 역량" 네트워크

**목적**: 개발자들이 직접 말한 _"AI가 강해져도 가치 있을 스킬"_ 을 카테고리→세부 역량 네트워크로.

**데이터**: 더미 — **Stack Overflow Annual Developer Survey 2025**의 **`AIOpen`** 주관식 문항을 모사
_"Looking ahead 3–5 years, what skills will remain valuable for developers even as AI tools become more capable?"_ (SO 2025 응답 22,555개)

**가공 방식 (실데이터 적용 시 — 핵심: 텍스트 마이닝)**

1. 정제(소문자·불용어·무의미 답변 제거)
2. 임베딩 + 클러스터링(예: HDBSCAN/K-means) **또는** 시드 카테고리 기반 분류
3. 클러스터 → 카테고리/세부 역량 라벨, **노드 크기 = 언급한 사람 수**
4. 클러스터별 **대표 인용문**(센트로이드 근접) 추출 → hover 팝업
5. (필터용) 각 노드의 **역할×연차 분포** 집계

> 현재 노드/인용/분포는 모두 **더미**. 위 파이프라인 산출물을 같은 구조(`CATS`, `SUBS`)에 끼우면 그대로 동작.

**필터**: 분야/역할(다중 선택 칩), 연차 범위(dual-range 슬라이더) → 노드 크기 재계산

**인터랙션**: 노드 hover→실제 답변 팝업+연결 강조, 클릭 고정, 드래그, 범례 카테고리 강조

## 4. `so_devs.html` — 개발자 개개인 산점도 (★ 실데이터)

**목적**: 점 하나 = 개발자 한 명. 경력·연봉·AI태도 등을 축/색으로 바꿔가며 개인 분포를 탐색.

**데이터**: 실데이터 — **Stack Overflow Annual Developer Survey 2025**
(`survey_results_public.csv`, 전체 49,191명) → 가공 후 `data/so_devs.js` (`window.SO_DEVS`)
연봉·경력이 모두 유효한 **22,858명 중 3,000명 무작위 표본**

**사용 필드 (SO 2025 원본 컬럼 → 가공)**

| 시각화 항목 | SO 원본 컬럼             | 가공                                            |
| ----------- | ------------------------ | ----------------------------------------------- |
| 코딩 경력   | `YearsCode`              | "Less than 1"→0.5, "More than 50"→51, 정수화    |
| 연봉        | `ConvertedCompYearly`    | USD, 1,000~400,000 범위 필터 (이상치 제거)      |
| 역할        | `DevType`                | 14개 그룹으로 축약(Full-stack/Back-end/…/Other) |
| AI 사용     | `AISelect`               | Daily/Weekly/Monthly/Plan to/Won't 5단계        |
| AI 위협인식 | `AIThreat`               | No/Unsure/Yes                                   |
| 연령        | `Age`                    | 6개 버킷                                        |
| 직무 만족도 | `JobSat`                 | 0–10 정수                                       |
| 학력        | `EdLevel`                | 학사/석사/… 축약                                |
| 근무형태    | `RemoteWork`             | 원격/하이브리드/출근/자율                       |
| 국가        | `Country`                | USA/UK 등 축약                                  |
| 주력 언어   | `LanguageHaveWorkedWith` | `;` 분해 후 상위 3개                            |

**가공 스크립트**: `data/build_so_devs.py` (원본 SO CSV → `so_devs.js`). 원본 CSV(약 140MB)는 미포함.

**축으로 선택 가능**

- 수치형: 코딩 경력 / 연봉(로그) / 직무 만족도
- 범주형: 역할 / AI 사용 / AI 위협인식 / 연령 / 근무형태
- 색상: 위 범주형 중 선택

**인터랙션**

- X/Y/색상 드롭다운 — 바꾸면 **3,000개 점이 force 시뮬레이션으로 재배치**(범주형 축이면 스웜으로 군집)
- 프리셋 6종(경력×연봉, 역할별 연봉, AI 사용별 연봉, 위협×만족도 등)
- **필터**: 국가, 분야, 연차 범위(dual-range) → 표시 점 수 감소
- 범례 클릭 → 그 집단만 격리(우측 통계·구성 갱신)
- 점 hover → 개발자 프로필 카드(역할·경력·연봉·언어·AI태도·만족도)
- 우측 패널: 선택 집단의 요약 통계 + 카테고리 구성(전체 평균 대비)

## 공통 설계 메모

- **정확도·신뢰는 작업별로 측정되지 않음** → 축이 아니라 "전반 게이지"로 분리(정직성 유지). 작업별 신뢰 대용은 JetBrains 위임 의향.
- **연차/역할/국가 필터를 공유**해 "집단을 나눠 봐도 경향이 유지되는가"를 검증 가능하도록 설계.
- 색상은 카테고리(작업 stage / 역할 등) 기준으로 통일해 뷰 간 인지적 연결 강화.
- 소스별 작업·역할·기술명 분류 체계가 달라, 실데이터 통합 시 **명칭 매핑표**가 전제.
